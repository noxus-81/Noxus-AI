# Mon Agent IA Local

Ce projet contient un agent IA autonome de base, conçu pour s'exécuter sur une Machine Virtuelle (VM) Windows.

## Comment l'installer sur votre Machine

1. **Copiez ce dossier** (`custom_agent`) sur votre Machine Windows.
2. **Installez Python** sur si ce n'est pas déjà fait.
3. Ouvrez un terminal (PowerShell ou CMD) dans ce dossier.
4. **Installez les dépendances** :
   ```bash
   pip install -r requirements.txt
   ```


## Comment le lancer

Exécutez le script avec Python :
```bash
python -m streamlit run web_agent.py```

L'agent va s'ouvrir dans votre navigateur. Nous tenons à préciser que notre IA est en cours de développement et peut faire des erreurs **
